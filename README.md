# MediFlow — Medical SaaS UI

Premium medical platform UI with landing page + doctor dashboard.

**Stack:** HTML5 · CSS3 · SVG  
**Fonts:** Cormorant Garamond · Outfit  
**Design:** Linear/Minimal · Light theme

### Pages
- `landing/index.html` — Marketing landing page
- `dashboard/index.html` — Doctor overview dashboard

### Features
- Patient queue with status tags
- Live vitals panel
- Weekly chart + donut breakdown
- Lab results tracker
- Fully responsive layout
