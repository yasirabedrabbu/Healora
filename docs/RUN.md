# Running Healora locally

## 1. Frontend + API (Next.js 16)

```bash
cd web
cp .env.example .env          # fill DATABASE_URL + AUTH_SECRET
npm install
npx prisma7 generate          # Prisma 7 CLI (see note)
npx prisma7 migrate dev       # needs a running PostgreSQL
node --env-file=.env prisma/seed.ts   # demo data (Handoff §13)
npm run dev                   # http://localhost:3000
```

> **Prisma 8 note:** the installed `prisma` CLI is v8 (no `generate`).
> `@prisma/prisma7@7` is installed for generation:
> `node node_modules/@prisma/prisma7/build/prisma7.js generate`
> Runtime uses `PrismaClient` from `@prisma/client` (generated by the 7 CLI).

Without a database the UI still runs - API routes return errors and the
frontend falls back to its typed mock data.

## 2. AI service (Python FastAPI)

```bash
cd ai-service
pip install -r requirements.txt
uvicorn app.main:app --port 8000     # http://localhost:8000
python -m pytest tests -q            # 16 tests
```

AI provider via env: `AI_PROVIDER=ollama` (default, local, data never
leaves) | `openai` (needs `AI_API_KEY`). When no provider is reachable the
service answers in safe degraded mode with the disclaimer intact.

## 3. Verification scripts

```bash
cd web
node scripts/audit-lines.mjs    # ≤200-line rule across src + ai-service
npm run build                   # full production build
npm start &                     # then:
node scripts/smoke.mjs          # 39-route smoke test (200 + key content)
```

## 4. Services summary

| Service | Port | Command |
|---|---|---|
| Next.js (UI + API) | 3000 | `npm run dev` |
| FastAPI AI | 8000 | `uvicorn app.main:app --port 8000` |
| PostgreSQL | 5432 | any local/Docker instance |
| Ollama (optional) | 11434 | `ollama serve` + `ollama pull llama3.1:8b` |
